Preguntas frecuentes

¿Cómo funciona el acceso?
Compras un plan, recibes un código de acceso y lo ingresas en la página para desbloquear el contenido. El código se vincula a tu correo y expira según los días del plan.
¿Puedo compartir mi código?
No. El código solo funciona con el correo con el que fue registrado. Si alguien más intenta usarlo, no va a funcionar.
¿Qué pasa cuando expira?
El código deja de funcionar automáticamente al terminar los días del plan. Puedes comprar uno nuevo cuando quieras.
¿Cómo pago?
El pago se coordina directamente con el vendedor. Una vez confirmado, te entregan tu código de acceso.
